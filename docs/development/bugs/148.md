# BUG-148 — Memory leak in `LRUCache.put` on `map.put` allocation failure

- **Status**: 🔴 Open
- **Severity**: 🟡 Medium-Low — heap allocation leak on map OOM
- **Files**: `src/utils/lru.zig:81-88`
- **Lessons**: [Zig §Lesson 77](../lessons/08-zig-specific-patterns.md)
- **Description**: In `LRUCache.put`:
  ```zig
  const node = try self.allocator.create(Node);
  node.* = .{
      .key = key,
      .value = value,
  };

  try self.map.put(key, node);
  ```
  If `self.map.put(key, node)` fails with `error.OutOfMemory`, `node` is never destroyed.
- **Trigger**: `error.OutOfMemory` during `self.map.put`.
- **Consequences**: Leaks the heap-allocated `Node` structure.
- **Proposed Fix**: Add `errdefer self.allocator.destroy(node);` immediately after creating `node`.
