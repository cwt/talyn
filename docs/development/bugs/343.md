# BUG-343 — Double-close and triple-close of socket `fd` on error paths in `z_loop_create_unix_server`

- **Status**: 🟢 Fixed
- **Severity**: 🔴 Critical — closing the same file descriptor 2–3 times on error in a multi-threaded or `io_uring` process can close an unrelated socket/file descriptor allocated concurrently by another thread
- **Category**: Double-Close
- **Files**:
  - `src/loop/python/io/pipe/unix.zig:206-251`
- **Related**: [Lesson 28](../lessons/02-zig-and-memory.md), [BUG-328](328.md)

## Overview & Root Cause

In `src/loop/python/io/pipe/unix.zig:206-251`, `z_loop_create_unix_server` registers two unconditional `errdefer _ = std.os.linux.close(fd);` statements in the same function scope and then transfers `fd` ownership to `StreamServer` without disarming either `errdefer`:

```zig
const sock_rc = std.os.linux.socket(std.posix.AF.UNIX, std.posix.SOCK.STREAM | std.posix.SOCK.CLOEXEC, 0);
if (@as(isize, @bitCast(sock_rc)) < 0) return error.SystemResources;
const fd: std.posix.fd_t = @intCast(sock_rc);
errdefer _ = std.os.linux.close(fd);
...
const bind_rc = std.os.linux.bind(fd, @ptrCast(&addr), @sizeOf(std.posix.sockaddr.un));
if (@as(isize, @bitCast(bind_rc)) < 0) return error.AddressInUse;
errdefer _ = std.os.linux.close(fd);
...
try StreamServer.init_from_fd(server, self, protocol_factory, fd, backlog);
errdefer python_c.py_decref(@ptrCast(server));
```

1. If `listen` fails (line 222) or `PyType_GenericAlloc` fails (line 228) or `StreamServer.init_from_fd` fails (line 231), **both** `errdefer _ = std.os.linux.close(fd)` statements at lines 218 and 209 execute, closing `fd` **twice**.
2. Once `StreamServer.init_from_fd` succeeds at line 231, `server` owns `fd` (and `stream_server_dealloc` closes `server.socket_fd` when `server` is decref'd). If `PyList_New(1)` fails at line 242 or `future_fast_set_result` fails at line 249, `errdefer python_c.py_decref(@ptrCast(server))` deallocates `server` (closing `fd` once), and then lines 218 and 209 close `fd` a **second** and **third** time.

## Trigger Scenario

1. Call `await loop.create_unix_server(factory, path)` when `listen()` fails or `StreamServer` initialization fails -> `fd` is closed twice.
2. Call `await loop.create_unix_server(factory, path)` when `PyList_New` or `future_fast_set_result` fails -> `fd` is closed three times.

## Proposed Remediation

Use a single `var owns_fd = true; errdefer if (owns_fd) { _ = std.os.linux.close(fd); };` after line 208, remove the duplicate `errdefer` at line 218, and set `owns_fd = false;` immediately after `try StreamServer.init_from_fd(...)` succeeds at line 231.
