# BUG-190 — Unchecked syscall return value in pseudosocket_getsockname yielding garbage memory

- **Status**: ✅ Fixed
- **Severity**: 🟡 Medium — Unchecked syscall return and uninitialized stack memory inspection
- **Files**: `src/utils/pseudosocket.zig:24-28`
- **Lessons**: [Defensive Programming §Lesson 53](../lessons/053-defensive-programming.md), [Zig Patterns §Lesson 77](../lessons/077-zig-patterns-and-idioms.md)
- **Description**: In `src/utils/pseudosocket.zig`, `pseudosocket_getsockname` executed:
  ```zig
  _ = std.os.linux.getsockname(instance.fd, @ptrCast(&addr), &addrlen);
  if (addrlen == 0 or addr.family == 0) { ... }
  ```
  The return code was ignored. If `getsockname` failed with `-EBADF` or `-ENOTSOCK`, `addr` contained uninitialized stack bytes. If random stack memory had non-zero family, it attempted to parse corrupt addresses.
- **Trigger**: Calling `getsockname()` on a PseudoSocket whose file descriptor is closed or invalid.
- **Consequences**: Stack memory leakage, invalid address parsing, or crashes.
- **Fix**: Replaced raw ignored syscall with `std.posix.getsockname` and proper error handling matching `pseudosocket_getpeername`.
