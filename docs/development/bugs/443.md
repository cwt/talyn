# BUG-443 — `MultiConnectState.init` OOM leak

- **Status**: 🟡 Open
- **Severity**: 🟢 Low — one-struct leak on OOM
- **Category**: Error path / allocation
- **Files**: `src/loop/python/io/client/create_connection/types.zig:183-194`
- **Related**: [BUG-88](088.md), [BUG-77](077.md)

## Description

```zig
const self = try allocator.create(MultiConnectState);
self.* = .{ ... };
if (all_errors) {
    self.exceptions = python_c.PyList_New(0) orelse return error.PythonError;   // self leaked
}
return self;
```

On `PyList_New` failure the freshly allocated `self` is not destroyed.

## Fix

`errdefer allocator.destroy(self);` immediately after `create`.
