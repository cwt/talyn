# BUG-152 — Unreachable dead code in `UnixSignals.unlink`

- **Status**: 🔴 Open
- **Severity**: 🟢 Low — dead code / unreachable logic
- **Files**: `src/loop/unix_signals.zig:199-225`
- **Lessons**: [Defensive §Lesson 98](../lessons/10-defensive-programming-and-code-quality.md), [Network Protocols §Lesson 81](../lessons/06-network-protocols-and-io.md)
- **Description**: In `src/loop/unix_signals.zig`, `unlink` contains a `switch (sig)` block (lines 182-197) where `std.os.linux.SIG.INT` executes `return;` and `else` also falls through to code that executes `return;`. Lines 199-225 (which construct a `default_sigint_signal_callback` and re-insert into `self.callbacks`) are completely unreachable.
- **Trigger**: None (unreachable dead code).
- **Consequences**: Confuses maintenance and code inspection.
- **Proposed Fix**: Remove the dead lines 199-225 from `UnixSignals.unlink`.
