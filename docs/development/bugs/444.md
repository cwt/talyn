# BUG-444 — io/scheduling dead code and micro-issues

- **Status**: 🟢 Fixed
- **Severity**: 🟢 Low — dead code / latent hazards / minor accounting
- **Category**: Code quality / io_uring
- **Files**: `src/loop/scheduling/io/main.zig`, `read.zig`, `types.zig`, `src/loop/scheduling/soon.zig`
- **Related**: [BUG-335](335.md), [BUG-27](027.md), [BUG-299](299.md), [BUG-364](364.md)

## Findings

1. **Unreachable `check_result` arms** (`io/main.zig:99-145`): cancels use `user_data=0` (skipped in
   `runner.zig:265`) and `SocketShutdown` is pushed with a null callback (`.none`), so the `.CancelIO/
   .CancelTimer/.CancelByFd/.SocketShutdown` arms never execute — dead code.
2. **`Read.PerformData.zero_copy` is a silent no-op** (`read.zig:81-92`): the `.buffer` arm ignores it;
   `MSG_ZEROCOPY` is transmit-only. Drop the field or reject it.
3. **`RegisteredBufferPool.release` overflow guard** (`types.zig:105-114`): `if (free_count >= SlotCount)
   return;` only catches the completely-full case; a duplicate release while `free_count < SlotCount`
   inserts the same index twice (two leases return the same buffer). Track per-slot leased state.
4. **`dispatch_guaranteed_nonthreadsafe`** (`soon.zig:22-27`): decrements `reserved_slots` before a
   fallible `push_or_grow`; on OOM the callback (and its owned refs) is dropped without `cleanup`.
   Push first, then decrement (or run cleanup on failure).
5. **`queue_unlocked`** (`io/main.zig:828-848`): calls `get_blocking_tasks_set()` for cancel variants
   that ignore the set — needless ~80 KB set allocation / `disattached` on a full set.
6. **`Read.perform` `.iovecs` path** (`read.zig:93`): passes a caller iovec array pointer to `prep_readv`
   (kernel-read at deferred submit); no current caller uses it, but it lacks the BUG-335 guard — reject
   `.iovecs`/`.buffer_selection` or copy into `BlockingTask` storage.

## Fix

Address each item independently (dead-code removal, guard, ordering, allocation skip).

## Resolution (2026-11-12)

All six sub-findings fixed:

1. **Dead `check_result` arms** — the `.CancelIO/.CancelTimer/.CancelByFd/.SocketShutdown` arms
   removed (check_result runs only from the runner's `.callback` arm; cancels never push a task and
   SocketShutdown pushes with a null callback). Unreachable operations fall through to the generic
   arm.
2. **`Read.PerformData.zero_copy` silent no-op** — the field is dropped (io_uring has no zero-copy
   receive; the flag was forwarded from `ReadTransport.zero_copying` and ignored, including
   `resolv/response.zig`'s `.zero_copy = true`). `ReadTransport` loses the field and its init
   parameter.
3. **`RegisteredBufferPool.release` duplicate release** — per-slot `leased: [SlotCount]bool` state
   added; a duplicate release is now a no-op in every pool state. The pool test gained a
   duplicate-release-while-not-full assertion.
4. **`dispatch_guaranteed_nonthreadsafe`** — pushes first, then decrements `reserved_slots`; an OOM
   no longer drops the callback with its owned references while the counter was already released.
5. **`queue_unlocked` needless set allocation** — `get_blocking_tasks_set()` now runs only for the
   task-pushing variants; cancel SQEs no longer allocate (or disattach) an ~80 KB set node.
6. **`Read.perform` `.iovecs` guard** — non-`.buffer` selectors are now rejected
   unconditionally (`error.NotImplemented`), not only when `zero_copy` was set; the `.iovecs`
   variant can no longer stage a caller array pointer for kernel-read at deferred submit.

Validation: `zig build test` green on Zig 0.16.0 and 0.17.1;
`./scripts/test_all.sh --python=3.15,3.15t --starburst --verbose` green (505 pytest passed on
py3.15, 504 + 1 skipped on py3.15t; stdlib asyncio green on both).
