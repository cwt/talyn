# BUG-261 — DNS `queue` errdefer leaks UDP socket fds for unsent server queries

- **Status**: 🟠 Open (confirmed real — 2026-08-21)
- **Validation**: 2026-08-21 — CONFIRMED REAL. In `resolv.zig` `queue()`, the `errdefer` cancels only `[0..queries_sent]` (closing their fds); the unsent tail `[queries_sent..]` is truncated away without `cancel()`/`close()`, leaking the `socket_fd`s opened in `build_queries`. In-flight sent queries keep `ControlData` alive via their completion callbacks, so the leaked resource is the fds themselves. Reachable under SQE-full pressure.
- **Severity**: Medium-High — File-Descriptor Leak / EMFILE Exhaustion
- **File**: `src/loop/dns/resolv.zig:786-797` (`queue` errdefer), `src/loop/dns/resolv.zig:566-640` (`build_queries` socket creation)
- **Lessons**: [io_uring & Kernel](../lessons/04-io-uring-and-kernel.md), [Network Protocols](../lessons/06-network-protocols-and-io.md), [Defensive Programming](../lessons/10-defensive-programming-and-code-quality.md)

## Description

`prepare_data` creates `queries_data.len == servers.len` (2-3) UDP sockets via `std.os.linux.socket` + `connect` in `build_queries`. `queue` then iterates:

```zig
var queries_sent: usize = 0;
errdefer {
    for (control_data.queries_data[0..queries_sent]) |*sd| sd.cancel();
    if (queries_sent==0) control_data.release()
    else control_data.queries_data = control_data.queries_data[0..queries_sent];
}
for (control_data.queries_data) |*sd| {
    _ = try loop.io.queue(.{ .PerformWrite = ... }); // may fail with SubmissionQueueFull
    queries_sent += 1;
}
```

If `queue` fails on the 2nd entry (`SubmissionQueueFull` under SQPOLL pressure), errdefer cancels sent entries and truncates slice to `0..1`. Unsent entries `1..len-1` are discarded (slice truncated) without `close()` or `cancel()`. Their `socket_fd` (opened in `build_queries`) leaks. Arena memory for those entries is freed on `ControlData.release`, but fds are not.

## Trigger

Sustained concurrent DNS under high SQE pressure (e.g., 1000 concurrent `getaddrinfo` with 3 `resolv.conf` servers) where `ring.sq_ready() >= TotalTasksItems-2` and `queue` flush fails.

## Consequences

- Permanent fd leak per failed DNS batch → eventual `EMFILE` / `ENFILE` → all outbound connects fail (related to [BUG-260](260.md) but distinct leak source).
- `buffer_pool` pressure if DNS path also uses fixed buffers.

## Fix (Not Applied)

In errdefer else-branch, close fds of truncated tail:

```zig
else {
    for (control_data.queries_data[queries_sent..]) |*sd| _ = std.os.linux.close(sd.socket_fd);
    control_data.queries_data = control_data.queries_data[0..queries_sent];
}
```

Or cancel all unsent via `sd.cancel()`.
