# BUG-136 — `WriteTransport.queue_eof` silently drops EOF request when write buffer is non-empty

- **Status**: ⚪ False Positive — tested design behavior in `tests/transports/test_stream.py::test_stream_transport_eof_with_pending_writes`
- **Severity**: 🟠 High
- **Files**: `src/transports/write_transport.zig:384-387`
- **Description**: `queue_eof` checks `if (self.buffer_size > 0) return;` by design, as verified by `test_stream_transport_eof_with_pending_writes`, which explicitly requires that attempted `write_eof()` calls during active writes do not close the socket and permit subsequent write operations.
