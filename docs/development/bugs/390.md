# BUG-390 — Server and endpoint creation bugs: `create_server(factory, sock=s)` fails without positional `host` and leaks earlier `StreamServer`s on partial multi-bind failure; `create_datagram_endpoint` ignores `sock=`; `create_unix_server` creates blocking socket and unlinks abstract socket paths

- **Status**: 🔴 Open
- **Severity**: 🟡 Medium — breaks `create_datagram_endpoint(factory, sock=s)` and ` _create_server_zig(factory, sock=s)`, leaves half-bound listening `StreamServer`s running in `io_uring` on dual-stack bind failure, and creates blocking listening sockets in `create_unix_server`
- **Category**: Logic Bug & Resource Leak
- **Files**:
  - `src/loop/python/io/server/create_server.zig:82-109, 420-534`
  - `src/loop/python/io/datagram/create_endpoint.zig:22, 70, 76, 101, 229-283`
  - `src/loop/python/io/pipe/unix.zig:206, 214`
- **Related**: [BUG-327](327.md), [Lesson 55](../lessons/06-network-protocols-and-io.md)

## Overview & Root Cause

1. **`z_create_server_socket` leaves earlier `StreamServer`s listening in `io_uring` if a subsequent address in `address_list` fails (`src/loop/python/io/server/create_server.zig:420-534`)**:
   When `host` resolves to multiple addresses (e.g., `"localhost"` resolving to both `127.0.0.1` and `::1`), `z_create_server_socket` loops over `address_list`, creating a `StreamServer`, calling `StreamServer.serve(server_obj)` (which registers a fixed file slot and arms an `io_uring` `Accept` task that holds a strong reference to `server_obj`), and appending `server_obj` to `servers_list`.
   If the first address (`127.0.0.1`) succeeds and the second address (`::1`) fails to bind with `EADDRINUSE` (line 489) or `StreamServer.serve` fails (line 511), `errdefer python_c.py_decref(servers_list)` decrefs `servers_list`, **but the first `StreamServer` is never closed (`StreamServer.close`)**, so its `io_uring` `Accept` task keeps the `StreamServer` alive and the TCP port bound forever!
   Also, in `z_loop_create_server` (`lines 82-109`), `if (args.len < 2)` is checked before `parse_vector_call_kwargs` parses `sock=`, so calling `_create_server_zig(factory, sock=s)` without positional `host` raises `ValueError`.

2. **`create_datagram_endpoint` completely ignores the `sock=` keyword argument (`src/loop/python/io/datagram/create_endpoint.zig:22, 70, 76, 101, 229-283`)**:
   `z_loop_create_datagram_endpoint` parses `sock` into `dcd.py_sock` (`line 101`), **and then never reads `dcd.py_sock` anywhere in `z_create_endpoint` (lines 229–283)**!
   Instead, `z_create_endpoint` unconditionally creates a brand new UDP socket via `std.os.linux.socket(family, ...)` at line 240, ignoring the caller's pre-bound `sock`!

3. **`z_loop_create_unix_server` creates the server socket without `SOCK.NONBLOCK` and calls `unlink` on abstract socket paths (`src/loop/python/io/pipe/unix.zig:206, 214`)**:
   - Line 206 calls `std.os.linux.socket(std.posix.AF.UNIX, std.posix.SOCK.STREAM | std.posix.SOCK.CLOEXEC, 0)` without `std.posix.SOCK.NONBLOCK` (unlike `z_loop_create_unix_connection` at line 153).
   - Line 214 calls `_ = std.os.linux.unlink(@ptrCast(&addr.path));` unconditionally before `bind()`, even when `path_slice` is a Linux abstract namespace socket (`path_slice[0] == 0`, where `&addr.path` is `""`) or when `path_slice` is not a socket file!

## Trigger Scenario

1. Pass a pre-bound `socket.socket(AF_INET, SOCK_DGRAM)` to `await loop.create_datagram_endpoint(factory, sock=s)` -> Talyn ignores `s` and creates a new unbound UDP socket instead.
2. Call `await loop.create_server(factory, "localhost", port)` when `127.0.0.1:port` is free and `[::1]:port` is already in use -> `create_server` raises `OSError(EADDRINUSE)`, but leaves `127.0.0.1:port` bound and accepting in `io_uring` forever.

## Proposed Remediation

1. In `z_create_server_socket` (`src/loop/python/io/server/create_server.zig:420-534`), add an `errdefer` that iterates over all `StreamServerObject` items already appended to `servers_list` and closes them (`StreamServer.stream_server_close`) if a subsequent address fails.
2. In `z_create_endpoint` (`src/loop/python/io/datagram/create_endpoint.zig:229-283`), check `if (dcd.py_sock) |sock_obj|`: dup/adopt the caller's `sock` file descriptor (and set `NONBLOCK`) instead of creating a new socket.
3. In `z_loop_create_unix_server` (`src/loop/python/io/pipe/unix.zig:206, 214`), include `std.posix.SOCK.NONBLOCK` in the `socket()` flags and only call `unlink` when `path_slice[0] != 0`.
