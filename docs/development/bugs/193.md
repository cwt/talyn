# BUG-193 — Missing tp_clear on GC heap types HookHandleType and PathWatcherHandleType

- **Status**: ✅ Fixed
- **Severity**: 🟡 Medium — Python cyclic GC leak
- **Files**: `src/loop/python/control.zig:164-171, 251-258`
- **Lessons**: [Python C API §Lesson 21](../lessons/021-python-c-api.md)
- **Description**: In `src/loop/python/control.zig`, both `HookHandleType` and `PathWatcherHandleType` were registered with `Py_TPFLAGS_HAVE_GC` and defined `tp_traverse`, but had no `tp_clear` slot function. Python cyclic GC relies on `tp_clear` to break cyclic dependencies during garbage collection.
- **Trigger**: Attaching cyclic references to hook handles or path watcher handles.
- **Consequences**: Permanent memory leaks of unreachable reference cycles.
- **Fix**: Implemented `tp_clear` and updated `tp_traverse` with `python_c.py_visit` for both `HookHandleType` and `PathWatcherHandleType`.
