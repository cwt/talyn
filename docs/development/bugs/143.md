# BUG-143 — Parent transport reference leak on I/O read error in `ReadTransport`

- **Status**: ✅ Fixed
- **Severity**: 🟠 High — strong reference leak of StreamTransport on connection errors
- **Files**: `src/transports/read_transport.zig:184-210`
- **Lessons**: [Memory §Lesson 107](../lessons/01-memory-and-reference-counting.md)
- **Description**: In `ReadTransport.read_operation_completed`, when an I/O error or callback exception occurred, `parent_transport` was not decref'd before returning.
- **Trigger**: Any socket read error (e.g. `ECONNRESET`, `ETIMEDOUT`, `EPIPE`).
- **Consequences**: Leaked 1 strong reference to the parent `StreamTransportObject` on every read error, preventing garbage collection.
- **Fix**: Added `python_c.py_decref(parent_transport);` on all error and exception exit paths in `read_operation_completed`.
