# BUG-199 — Unchecked getsockname syscall return in DatagramTransport.z_datagram_sendto reads uninitialized memory

- **Status**: ✅ Fixed
- **Severity**: 🟡 Medium — Defensive Programming & Uninitialized Memory
- **Files**: `src/transports/datagram/write.zig:145-147`, `src/transports/datagram/extra_info.zig:36-38`
- **Lessons**: [Defensive Programming §Lesson 53](../lessons/10-defensive-programming-and-code-quality.md), [BUG-190](190.md)
- **Description**: In `src/transports/datagram/write.zig` and `src/transports/datagram/extra_info.zig`, `getsockname` syscall return value was discarded. If `getsockname` failed, `storage.family` contained uninitialized stack memory, which was then passed to `Address.fromPyAddr`.
- **Trigger**: `sendto(data, addr)` or `get_extra_info("sockname")` on an invalid or closing datagram socket descriptor.
- **Consequences**: Stack garbage memory interpreted as address family, leading to parsing failures or unpredictable address family resolution.
- **Fix**: Validated `std.posix.errno(rc) == .SUCCESS` on `getsockname` before accessing `storage.family` across `write.zig` and `extra_info.zig`.
