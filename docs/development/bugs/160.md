# BUG-160 — Tautological unsigned comparison and missing error check in `pseudosocket_setsockopt`

- **Status**: ✅ Fixed
- **Severity**: 🟢 Low — dead code / unchecked conversion
- **Files**: `src/utils/pseudosocket.zig:97-102`
- **Lessons**: [Defensive §Lesson 12](../lessons/10-defensive-programming-and-code-quality.md)
- **Description**: In `src/utils/pseudosocket.zig`, `pseudosocket_setsockopt` casts the second tuple argument to `u32` for `optname` and checks `if (level < 0 or optname < 0)`. The condition `optname < 0` is tautologically false for unsigned `u32`. Furthermore, if `PyLong_AsLong` fails and returns `-1`, `@intCast` is invoked without checking `PyErr_Occurred()`.
- **Trigger**: Calling `setsockopt` with invalid argument types or negative options on a `PseudoSocket`.
- **Consequences**: Unchecked Python error state and dead branch comparison.
- **Fix**: Checked `PyErr_Occurred()` after `PyLong_AsLong` calls, validated signed integers for negativity, and then cast to `i32`/`u32`.
