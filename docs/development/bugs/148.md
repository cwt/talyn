# BUG-148 — Memory leak in `LRUCache.put` on `map.put` allocation failure

- **Status**: ✅ Fixed
- **Severity**: 🟡 Medium-Low — heap allocation leak on map OOM
- **Files**: `src/utils/lru.zig:81-88`
- **Lessons**: [Zig §Lesson 77](../lessons/08-zig-specific-patterns.md)
- **Description**: In `LRUCache.put`, `node` was allocated before `self.map.put(key, node)` without `errdefer self.allocator.destroy(node);`.
- **Trigger**: `error.OutOfMemory` during `self.map.put`.
- **Consequences**: Leaked the heap-allocated `Node` structure on map insertion failure.
- **Fix**: Added `errdefer self.allocator.destroy(node);` immediately after `self.allocator.create(Node)`.
