# BUG-199 — Unchecked getsockname syscall return in DatagramTransport.z_datagram_sendto reads uninitialized memory

- **Status**: 🔴 Open
- **Severity**: 🟡 Medium — Defensive Programming & Uninitialized Memory
- **Files**: `src/transports/datagram/write.zig:145-147`
- **Lessons**: [Defensive Programming §Lesson 53](../lessons/053-defensive-programming.md), [BUG-190](190.md)
- **Description**: In `src/transports/datagram/write.zig`, `z_datagram_sendto` queries the socket's family via `_ = std.os.linux.getsockname(self.fd, @ptrCast(&storage), &addrlen);` without checking the syscall return value. If `getsockname` fails, `storage.family` contains uninitialized stack memory, which is then passed to `Address.fromPyAddr`.
- **Trigger**: `sendto(data, addr)` on a corrupted, closed, or invalid datagram socket descriptor.
- **Consequences**: Stack garbage memory interpreted as address family, leading to parsing failures or unpredictable address family resolution.
- **Proposed Fix**: Check `std.posix.errno(ret) == .SUCCESS` on `getsockname`; if unsuccessful, leave `family = null` or fall back safely.
