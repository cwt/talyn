# BUG-141 — PEP 695 generic syntax in `task.py` and `runner.py` incompatible with Python 3.8–3.11

- **Status**: 🔴 Open
- **Severity**: 🟡 Medium — syntax error on target Python versions 3.8–3.11
- **Files**: `talyn/task.py:7`, `talyn/runner.py:27, 44`
- **Lessons**: [Python C API §Lesson 27](../lessons/05-python-c-api-correctness.md)
- **Description**: `talyn/task.py` declares `class Task[T](_Task):` and `talyn/runner.py` declares `def run[T](...):`. The `[T]` type parameter syntax was introduced in Python 3.12 (PEP 695) and causes an uncatchable `SyntaxError` during module compilation on Python 3.8, 3.9, 3.10, and 3.11.
- **Trigger**: Importing `talyn` under Python 3.8, 3.9, 3.10, or 3.11.
- **Consequences**: `SyntaxError: invalid syntax` on module import.
- **Proposed Fix**: Use standard `TypeVar` syntax from `typing` (e.g. `T = TypeVar("T")` and `Generic[T]`), preserving compatibility with Python 3.8–3.10.
