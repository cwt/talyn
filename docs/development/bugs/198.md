# BUG-198 — execute_task_send leaks PythonTaskObject reference if future_fast_set_exception errors

- **Status**: ✅ Fixed
- **Severity**: 🟡 Medium — Python Reference Count Leak
- **Files**: `src/task/callbacks.zig:538-547`
- **Lessons**: [Memory & Refcounting §Lesson 2](../lessons/01-memory-and-reference-counting.md)
- **Description**: In `src/task/callbacks.zig`, `execute_task_send` and `execute_task_throw` handle errors in a `catch` block that called `try Future.Python.Result.future_fast_set_exception(&task.fut, fut, exc);`. If `future_fast_set_exception` failed, the `try` returned early, skipping `python_c.py_decref(@ptrCast(task));`.
- **Trigger**: Memory allocation failure or error during exception propagation to task done callbacks.
- **Consequences**: Permanent leak of the `PythonTaskObject` reference count.
- **Fix**: Added `errdefer python_c.py_decref(@ptrCast(task));` before `future_fast_set_exception` across `execute_task_throw` and `execute_task_send`.
