# BUG-145 — Double decref and use-after-free of `loop` in `create_server` with custom socket

- **Status**: ✅ Fixed
- **Severity**: 🔴 Critical — use-after-free and reference count underflow on Loop object
- **Files**: `src/loop/python/io/server/create_server.zig:225`
- **Lessons**: [Memory §Lesson 14](../lessons/01-memory-and-reference-counting.md), [Memory §Lesson 106](../lessons/01-memory-and-reference-counting.md)
- **Description**: In `z_loop_create_server` when `py_sock` was provided, `python_c.deinitialize_object_fields(creation_data_ptr, ...)` omitted `"loop"`, causing premature decref and double-decref during callback `deinit()`.
- **Trigger**: Calling `loop.create_server(..., sock=existing_socket)`.
- **Consequences**: Premature deallocation and memory corruption of the `Loop` Python object.
- **Fix**: Added `"loop"` to the exclude list in line 225: `&.{ "future", "protocol_factory", "loop" }`.
