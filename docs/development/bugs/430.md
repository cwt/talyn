# BUG-430 — Datagram `sendto` low-water check runs before the buffer_size decrement

- **Status**: 🟡 Open
- **Severity**: 🟡 Medium — flow-control (resume_writing) missed
- **Category**: Flow control / defer ordering
- **Files**: `src/transports/datagram/write.zig:26-62`
- **Related**: [BUG-408](408.md), [BUG-34](034.md)

## Description

```zig
defer self.buffer_size -= @min(self.buffer_size, sd.buf.len);   // runs at function exit
...
if (!self.is_writing and self.buffer_size <= self.writing_low_water_mark) {  // stale value
    self.is_writing = true;
    ... resume_writing ...
}
```

The `defer` runs **after** the low-water check, so the completed datagram's bytes are still included
in `buffer_size` when the comparison happens. The transition to `resume_writing` can be missed.

## Trigger

A datagram completion that brings the buffer from above to at/below the low-water mark.

## Consequences

Application flow control stalls (no `resume_writing`), reducing throughput.

## Fix

Decrement `buffer_size` **before** the low-water check (drop the `defer`, or use an explicit local and
assign before the check).
