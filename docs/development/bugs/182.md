# BUG-182 — Use-after-free in ChildWatcher.on_child_exit on cancelled CQE dereferencing destroyed handler

- **Status**: ✅ Fixed
- **Severity**: 🔴 Critical — Heap use-after-free during event loop shutdown
- **Files**: `src/loop/child_watcher.zig:96-101`
- **Lessons**: [Lifecycle & Shutdown §Lesson 29](../lessons/029-lifecycle-and-shutdown.md), [Memory Management & Refcounting §Lesson 04](../lessons/004-memory-management-and-refcounting.md)
- **Description**: In `src/loop/child_watcher.zig`, `on_child_exit` started with:
  ```zig
  const handler: *ChildHandler = @ptrCast(@alignCast(data.user_data.?));
  const self = handler.watcher;
  if (data.cancelled() or !self.loop.initialized) return;
  ```
  During `Loop.release()`, `ChildWatcher.deinit()` is called, which frees all allocated `ChildHandler` structs. When cancelled CQEs drain, `on_child_exit` accessed `handler.watcher` *before* checking `data.cancelled()`, reading from already-freed heap memory.
- **Trigger**: Closing/releasing the event loop while child watchers are active.
- **Consequences**: Heap use-after-free, memory corruption, or crash during event loop shutdown.
- **Fix**: Placed `if (data.cancelled()) return;` before `@ptrCast` and accessing `handler.watcher`.
