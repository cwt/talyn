# BUG-146 — `OSError` reference leak on single connection failure in `create_connection`

- **Status**: ✅ Fixed
- **Severity**: 🟡 Medium-High — Python object leak on connection failure
- **Files**: `src/loop/python/io/client/create_connection.zig:874-889`
- **Lessons**: [Memory §Lesson 30](../lessons/01-memory-and-reference-counting.md), [Memory §Lesson 36](../lessons/01-memory-and-reference-counting.md)
- **Description**: In `socket_connected_callback`, when a single connection attempt failed, `exc` was created with `PyObject_CallFunction` and passed to `future_fast_set_exception` without a balancing decref.
- **Trigger**: Any failed TCP connection attempt via `loop.create_connection()`.
- **Consequences**: Leaked 1 `OSError` instance per failed connection.
- **Fix**: Added `defer python_c.py_decref(exc);` after `PyObject_CallFunction` returns.
