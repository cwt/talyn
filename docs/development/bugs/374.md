# BUG-374 — Reference leaks (`_asyncio_future_blocking`, `Py_False`) and unbroken `wake_up_task_callback` reference cycle in `handle_legacy_future_object`

- **Status**: 🔴 Open
- **Severity**: 🔴 High — leaks `_asyncio_future_blocking` and `Py_False` on every await of a foreign/stdlib `asyncio.Future`, and creates a reference cycle (`task -> wake_up_task_callback -> task`) that prevents immediate reference-count deallocation of any `Task` that ever awaited a foreign `Future`
- **Category**: Reference Leak
- **Files**:
  - `src/task/callbacks.zig:165-182, 285-333`
- **Related**: [Lesson 41](../lessons/05-python-c-api-correctness.md), [Lesson 44](../lessons/05-python-c-api-correctness.md)

## Overview & Root Cause

In `src/task/callbacks.zig:285-333`, `handle_legacy_future_object` handles awaiting a non-Talyn `Future` (such as a stdlib `asyncio.Future` or `concurrent.futures.Future` wrapper):

```zig
const asyncio_future_blocking = python_c.PyObject_GetAttrString(result, "_asyncio_future_blocking\x00");
if (asyncio_future_blocking) |blocking| {
    if (python_c.Py_IsNone(blocking) != 0) {
        python_c.PyErr_SetString(python_c.PyExc_RuntimeError, "Task cannot await on a coroutine object\x00");
        return error.PythonError;
    }

    if (python_c.Py_IsTrue(blocking) == 0) {
        python_c.PyErr_Format(
            python_c.PyExc_RuntimeError,
            "yield was used instead of yield from in task %R with %R\x00",
            task, result
        );
        return error.PythonError;
    }
} else {
    python_c.PyErr_Clear();
    return false;
}

if (python_c.PyObject_SetAttrString(result, "_asyncio_future_blocking\x00", python_c.get_py_false()) < 0) {
    return error.PythonError;
}

const add_done_callback = python_c.PyObject_GetAttrString(result, "add_done_callback\x00") orelse return error.PythonError;
defer python_c.py_decref(add_done_callback);

if (task.wake_up_task_callback == null) {
    task.wake_up_task_callback = python_c.PyCFunction_New(&WakeUpTaskMethodDef, @ptrCast(task)) orelse return error.PythonError;
}
```

There are three reference leaks in this function:

1. **`blocking` (`_asyncio_future_blocking`) is never decref'd (line 300)**:
   `PyObject_GetAttrString(result, "_asyncio_future_blocking\x00")` returns a **new reference** (`blocking`), which has no `defer python_c.py_decref(blocking);` on either the success path or the two error paths!

2. **`python_c.get_py_false()` is never decref'd (line 318)**:
   `PyObject_SetAttrString` does **not** steal a reference to its value argument, yet `python_c.get_py_false()` increments `Py_False`'s reference count (`py_newref`). It should pass `python_c.get_py_false_without_incref()`.

3. **Self-referential cycle `task -> task.wake_up_task_callback -> task` is never broken on task completion (lines 165–182, 324–326)**:
   `PyCFunction_New(&WakeUpTaskMethodDef, @ptrCast(task))` increments `task`'s reference count (`m_self = task`), and `task.wake_up_task_callback` stores a strong reference to that `PyCFunction`.
   When the task completes in `set_result` (`src/task/callbacks.zig:165-182`), `task.coro` and `task.fut_waiter` are cleared, **but `task.wake_up_task_callback` is NOT cleared**!
   Thus `task` and `task.wake_up_task_callback` remain in a permanent reference cycle until CPython's cyclic garbage collector runs (and on free-threaded Python 3.13t/3.14t where `talyn.install()` disables `gc` at `talyn/__init__.py:51`, it is leaked forever!).

## Trigger Scenario

Await any stdlib `asyncio.Future` (or `loop.run_in_executor(...)`, which uses `asyncio. wrap_future` on a `concurrent.futures.Future`) inside a Talyn `Task`. Every await leaks `blocking` and `Py_False`, and keeps the `Task` alive in a reference cycle after completion.

## Proposed Remediation

1. Add `defer python_c.py_decref(blocking);` at line 301.
2. Replace `python_c.get_py_false()` with `python_c.get_py_false_without_incref()` at line 318.
3. In `set_result` (`src/task/callbacks.zig:165-182`, inside `defer`), clear `python_c.py_xdecref(task.wake_up_task_callback); task.wake_up_task_callback = null;`.
