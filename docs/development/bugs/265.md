# BUG-265 — Duplicate `set_future_exception` helpers across 5 files

- **Status**: 🟢 Open (confirmed real — 2026-08-21)
- **Validation**: 2026-08-21 — CONFIRMED REAL (duplication). The helper is defined identically in **5** files, not 4: `socket/ops.zig:16`, `client/create_connection.zig:100`, `datagram/create_endpoint.zig:49`, `pipe/unix.zig:16`, `server/create_server.zig:60`. Maintainability/fix-drift risk (a fix to exception handling must be applied 5×), not a correctness defect.
- **Severity**: Low — Duplicated Logic / Fix-Drift Risk
- **Files**:
  - `src/loop/python/io/socket/ops.zig:16-22`
  - `src/loop/python/io/client/create_connection.zig:100-107`

  - `src/loop/python/io/pipe/unix.zig:16-22`
- **Lessons**: [Defensive Programming & Code Quality](../lessons/10-defensive-programming-and-code-quality.md)

## Description

Each file defines:

```zig
fn set_future_exception(err: anyerror, future: *FutureObject) !void {
    utils.handle_zig_function_error(err, {});
    const exc = PyErr_GetRaisedException() orelse return error.PythonError;
    defer py_decref(exc);
    const fd = get_data_ptr(Future, future);
    try future_fast_set_exception(future, fd, exc);
}
```

Fix to error handling (e.g., adding `PyErr_Clear` on `PyErr_GetRaisedException()==null`) must be applied 5 times. Audit history shows [BUG-90](../090.md) required touching all 5, one was missed initially.

## Consequences

- Fix drift → one path leaks exception state.

## Fix (Not Applied)

Extract to `src/utils/python_future.zig` helper `setFutureException(err, future)`.
