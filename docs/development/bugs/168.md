# BUG-168 — File descriptor leak on `tp_alloc` failure in `pseudosocket_dup`

- **Status**: ✅ Fixed
- **Severity**: 🟠 High — file descriptor leak on error
- **Files**: `src/utils/pseudosocket.zig:189-200`
- **Lessons**: [Resource Cleanup §Lesson 04](../lessons/03-event-loop-lifecycle.md)
- **Description**: In `src/utils/pseudosocket.zig`, `pseudosocket_dup` duplicates the internal file descriptor using `std.os.linux.dup(instance.fd)`. If `fast_new_pseudosocket` fails (for instance, when `tp_alloc` returns `null` under memory pressure), the catch block previously returned `null` without closing `new_fd`.
- **Trigger**: Duplicating a pseudo-socket under low-memory conditions.
- **Consequences**: Permanent leak of duplicated file descriptors in the kernel table.
- **Fix**: Closed `new_fd` in the catch block before raising `ValueError` and returning `null`.
