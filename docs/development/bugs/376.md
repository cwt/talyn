# BUG-376 — `create_server` and `_create_ssl_server` never wire `srv.server_ref = server`, breaking `Server.wait_closed()` active connection tracking

- **Status**: 🔴 Open
- **Severity**: 🔴 High — breaks Python 3.12+/3.13+ `Server.wait_closed()` active connection tracking for all TCP (`loop.create_server`) and SSL (`_create_ssl_server`) servers
- **Category**: Logic Bug
- **Files**:
  - `talyn/loop.py:1091-1100, 1257-1265, 1503-1506`
  - `talyn/server.py:8-12, 51-67`
  - `src/transports/streamserver/main.zig:84-90, 200-209`
- **Related**: [Lesson 55](../lessons/06-network-protocols-and-io.md)

## Overview & Root Cause

In `src/transports/streamserver/main.zig:84-90, 200-209`, `StreamServer` calls `server_ref._attach()` when a client connection is accepted and wraps `protocol.connection_lost` with `_ClientProtocolWrapper` to call `server_ref._detach()` when the client connection closes — **if and only if `srv.server_ref` is set on the `StreamServer` instance**.

Look at `create_unix_server` in `talyn/loop.py:1503-1506`:

```python
server = Server(self, srvs)
for srv in srvs:
    srv.server_ref = server
return server
```

Now look at `create_server` (`talyn/loop.py:1091-1100`) and `_create_ssl_server` (`talyn/loop.py:1257-1265`):

```python
srvs = await self._create_server_zig(
    protocol_factory, host, port, **zig_kwargs
)
return Server(self, srvs)
```

Neither `create_server` nor `_create_ssl_server` sets `srv.server_ref = server` (and `Server.__init__` in `talyn/server.py:8-12` does not set it either)!
As a result:
- `srv.server_ref` is always `null` for every TCP and SSL `Server`.
- `server._attach()` and `server._detach()` are never called when clients connect or disconnect.
- `server._active_count` is permanently `0`.
- Calling `server.close()` followed by `await server.wait_closed()` resolves immediately even while active client connections are still open and transferring data (violating Python 3.12+/3.13+ `Server.wait_closed()` semantics).

## Trigger Scenario

1. Create a TCP server via `server = await loop.create_server(factory, '127.0.0.1', 0)`.
2. Connect a client so a connection is active.
3. Call `server.close()` -> `server._Wakeup()` sees `self._active_count == 0` and immediately resolves `await server.wait_closed()` while the client connection is still open!

## Proposed Remediation

Set `srv.server_ref = self` directly inside `Server.__init__` in `talyn/server.py:8-12` so that all `Server` instances (`create_server`, `_create_ssl_server`, and `create_unix_server`) automatically wire `server_ref`:

```python
class Server(asyncio.AbstractServer):
    def __init__(self, loop, servers):
        self._loop = loop
        self._servers = servers
        self._waiters = []
        self._active_count = 0
        self._serving = True
        for srv in servers:
            srv.server_ref = self
```
