# BUG-421 — DNS resolv.conf short read parses uninitialized bytes

- **Status**: 🟡 Open
- **Severity**: 🟠 High — wrong nameservers / malformed config from uninitialized memory
- **Category**: Syscall handling / input validation
- **Files**: `src/loop/dns/main.zig:68-86`, `src/loop/dns/parsers.zig:152-239`
- **Related**: [BUG-90](090.md) (resolv.conf whitespace), [BUG-326](326.md) (raw-syscall errno)

## Description

```zig
const content = try allocator.alloc(u8, size);   // undefined contents
defer allocator.free(content);

const read_ret = std.os.linux.read(fd, content.ptr, content.len);
if (utils.getSyscallErrno(read_ret) != .SUCCESS) return error.Unexpected;

self.configuration = try Parsers.parse_resolv_configuration(allocator, content);
```

Only the negative/error case is checked. `read(2)` may legitimately return **fewer** bytes than
requested (file truncated after `statx`, a signal, or a non-regular file). The code then parses
the *entire* `content` slice — `[read_ret..size]` is still **undefined** — so garbage can be
interpreted as `nameserver`/`search` lines.

## Trigger

`/etc/resolv.conf` shrinks between `statx` and `read`, or the read is interrupted/short.

## Consequences

Wrong DNS servers, spurious search domains, or parser input derived from uninitialized memory.

## Fix

Clamp to the actual count and reject an empty read of a non-empty file:

```zig
const n = std.os.linux.read(fd, content.ptr, content.len);
if (utils.getSyscallErrno(n) != .SUCCESS) return error.Unexpected;
if (n == 0) return error.Unexpected;
self.configuration = try Parsers.parse_resolv_configuration(allocator, content[0..n]);
```
