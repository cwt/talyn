# BUG-230 — `ControlData.traverse` skips GC-visible `record` and `queries_data` PyObject fields

- **Status**: 🔴 Open
- **Severity**: 🟡 Medium — Ghost reference cycle / OOM
- **File**: `src/loop/dns/resolv.zig:~165-180` (ControlData.traverse)
- **Lessons**: [Memory §Lesson 3 — Ghost Reference Cycle (GC invisibility)](../lessons/01-memory-and-reference-counting.md), [Memory §Lesson 11 — Ghost Reference Cycle in Future Callbacks](../lessons/01-memory-and-reference-counting.md), [Memory §Lesson 14 — Gap in deinitialize_object_fields](../lessons/01-memory-and-reference-counting.md)
- **Description**: `ControlData.traverse` (resolv.zig) only visits `user_callbacks` entries but omits two critical PyObject-bearing fields:

  1. **`record: *Cache.Record`** — The `Record` struct holds a `RecordState` union that may contain resolved address lists and, via `set_resolved_data`/`set_ptr_data`, can reference other objects. More importantly, the `ControlData` itself is referenced from `Cache.Record.pending` state, creating a cycle: `Record → ControlData → Record`.
  2. **`queries_data: []ServerQueryData`** — Each `ServerQueryData` holds a `control_data` back-pointer and `loop` reference. The slice header itself doesn't hold PyObjects, but the individual `ServerQueryData` entries within it may reference Python objects through their io_uring callback chains.

  Per BUG-3/BUG-11/BUG-110 lessons, any native structure holding a `PyObject*` must appear in `tp_traverse`. Skipping even one arm creates ghost references invisible to the GC, leading to OOM on long-running processes.

- **Trigger**: Long-running DNS resolution with pending queries that survive GC cycles (e.g., keepalive connections with DNS caching).
- **Consequences**: Ghost reference cycles invisible to Python GC → eventual OOM as DNS control data accumulates without being collected.
- **Fix**: Add `record` and `queries_data` traversal arms to `ControlData.traverse`. For `record`, traverse through its state if pending. For `queries_data`, traverse each entry's loop reference if present.
