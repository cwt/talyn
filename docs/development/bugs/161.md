# BUG-161 — Prohibited `lambda` function in `talyn/loop.py` `_TransportWrapper.get_extra_info`

- **Status**: 🔴 Open
- **Severity**: 🟢 Low — rule compliance / code quality
- **Files**: `talyn/loop.py:1991`
- **Lessons**: [Defensive §Lesson 12](../lessons/10-defensive-programming-and-code-quality.md)
- **Description**: In `talyn/loop.py`, `_TransportWrapper.get_extra_info` contains `getattr(self._transport, "get_extra_info", lambda *a, **k: default)(name, default)`. This violates the repository coding rule prohibiting all `lambda` functions.
- **Trigger**: None (style and code convention violation).
- **Consequences**: Rule inconsistency and potential difficulty debugging anonymous callables.
- **Proposed Fix**: Replace the inline `lambda` with an explicitly named helper function `def _default_extra_info(*args: Any, **kwargs: Any) -> Any:`.
