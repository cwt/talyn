# BUG-178 — Allocator mismatch / invalid free in ServerQueryData.release

- **Status**: ✅ Fixed
- **Severity**: 🔴 Critical — Memory allocator metadata corruption and invalid pointer free
- **Files**: `src/loop/dns/resolv.zig:130-137`
- **Lessons**: [Memory Management & Refcounting §Lesson 04](../lessons/01-memory-and-reference-counting.md), [Zig Patterns §Lesson 77](../lessons/08-zig-specific-patterns.md)
- **Description**: In `src/loop/dns/resolv.zig`, `ServerQueryData.release()` frees `self.ptr_results` and `self.queries` using `control_data.allocator.free()`. However, `self.queries`, `ptr_name`, and `self.ptr_results` were allocated using `control_data.arena.allocator()`. `control_data.allocator` is the parent General Purpose Allocator / `c_allocator`. Passing arena-allocated memory to GPA `free()` triggers `free(): invalid pointer` crashes. Furthermore, `control_data.release()` already tears down the entire arena via `self.arena.deinit()`.
- **Trigger**: Teardown of DNS server query data after query completion or cancellation.
- **Consequences**: Heap corruption, allocator crashes, and undefined behavior.
- **Fix**: Removed individual `control_data.allocator.free()` calls in `ServerQueryData.release()`, relying on arena teardown in `control_data.release()`.
