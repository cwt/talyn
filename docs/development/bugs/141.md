# BUG-141 — PEP 695 generic syntax in `task.py` and `runner.py` incompatible with Python 3.8–3.11

- **Status**: ✅ Fixed
- **Severity**: 🟡 Medium — syntax error on target Python versions 3.8–3.11
- **Files**: `talyn/task.py:7`, `talyn/runner.py:27, 44`, `talyn/loop.py:474, 495`
- **Lessons**: [Python C API §Lesson 27](../lessons/05-python-c-api-correctness.md)
- **Description**: `talyn/task.py`, `talyn/runner.py`, and `talyn/loop.py` used PEP 695 `[T]` generic syntax introduced in Python 3.12, causing `SyntaxError` on Python 3.8–3.11.
- **Trigger**: Importing `talyn` under Python 3.8, 3.9, 3.10, or 3.11.
- **Consequences**: `SyntaxError: invalid syntax` on module import.
- **Fix**: Replaced PEP 695 syntax with standard `typing.TypeVar` and `typing.Generic` definitions across all Python files.
