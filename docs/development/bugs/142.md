# BUG-142 — Double-add of `Loop` type object in `src/lib.zig` causes reference count underflow

- **Status**: ✅ Fixed
- **Severity**: 🔴 Critical — reference count underflow / premature deallocation of Loop type
- **Files**: `src/lib.zig:125-141`
- **Lessons**: [Memory §Lesson 52](../lessons/01-memory-and-reference-counting.md)
- **Description**: In `src/lib.zig`, `LoopType` was registered to the module once explicitly before iterating over `dynamic_talyn_modules_names`, calling `PyModule_AddObject` twice on `LoopType`.
- **Trigger**: Extension module initialization during `import talyn`.
- **Consequences**: `PyModule_AddObject` stole a reference twice without an intermediate incref, resulting in reference count underflow on `LoopType`.
- **Fix**: Removed the duplicate explicit `PyModule_AddObject(module, "Loop\x00", ...)` before the loop, registering `Loop` once via `dynamic_talyn_modules_names`.
