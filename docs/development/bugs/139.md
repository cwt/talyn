# BUG-139 — Argument order mismatch in `create_unix_server` constructor call (`backlog` passed as `family`)

- **Status**: ✅ Fixed
- **Severity**: 🟡 Medium-High — corrupted socket address family on Unix domain server sockets
- **Files**: `src/loop/python/io/pipe/unix.zig:228-245`, `src/transports/streamserver/main.zig:159-160`
- **Lessons**: [Network Protocols §Lesson 31](../lessons/06-network-protocols-and-io.md), [Defensive §Lesson 101](../lessons/10-defensive-programming-and-code-quality.md)
- **Description**: `z_loop_create_unix_server` invoked `StreamServer` instantiation with `"OOOi\x00"` passing `backlog` as the 4th argument, setting `self.family = backlog` instead of `AF_UNIX`.
- **Trigger**: Creating a Unix domain socket server via `loop.create_unix_server()`.
- **Consequences**: Calling `server.sockets` returned socket objects with invalid address family `100`.
- **Fix**: Passed `py_family_obj` (`AF_UNIX` = 1) as the 4th argument and `py_backlog_obj` as the 5th argument with format `"OOOOO\x00"` in `src/loop/python/io/pipe/unix.zig`.
