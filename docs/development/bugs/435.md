# BUG-435 — `cancel_all` leaks the reserved slot for `.none` tasks

- **Status**: 🟢 Fixed
- **Severity**: 🟡 Medium — `reserved_slots` drift / slot leak at teardown
- **Category**: Accounting / teardown
- **Files**: `src/loop/scheduling/io/main.zig:196-206`, `src/loop/scheduling/io/socket.zig:40-48`
- **Related**: [BUG-364](364.md), [BUG-240](240.md)

## Description

```zig
pub fn cancel_all(self: *BlockingTasksSet, loop: *Loop) !void {
    for (self.task_data_pool[0..self.index]) |*task| {
        switch (task.data) {
            .callback => |*data| { ... dispatch_guaranteed_nonthreadsafe ... },
            .none => {},   // <-- no reserved_slots adjustment, no pop
        }
    }
}
```

`Socket.shutdown` pushes with `callback = null`, so `data == .none`; its `push()` reserved a slot but
`cancel_all` never releases it.

## Trigger

Loop teardown with an outstanding `SocketShutdown` (null-callback) task.

## Consequences

`reserved_slots` drifts upward; the slot is never returned to the free list.

## Fix

Decrement `reserved_slots` (or `pop()` the task) for every live task, not just `.callback` ones.

## Resolution (2026-11-12)

`cancel_all`'s `.none` arm now releases the reserved loop slot for **live** null-callback tasks.
Validation refined the filing: `pop()`/`reset()` poison completed slots to `data = .none` —
indistinguishable from a live null-callback push by `data` alone — so the sweep needed a per-slot
liveness flag. `BlockingTask` gained `live: bool` (set by `push` before the Mandate-#5 index
advance, cleared by `reset()`), and the `.none` arm decrements `reserved_slots` only for live
slots. The slot itself is deliberately **not popped** during the sweep: `pop` can hit
`active_tasks == 0` and free the set node mid-iteration, and the whole set dies with the IO at
teardown anyway.

The first fix attempt (unconditional decrement) was caught immediately by the BUG-02/BUG-334
link-timeout unit tests (underflow on dead `.none` slots) — the liveness flag is the regression
guard for exactly that.

Validation: `zig build test` green on Zig 0.16.0 and 0.17.1;
`./scripts/test_all.sh --python=3.15,3.15t --starburst --verbose` green (505 pytest passed on
py3.15, 504 + 1 skipped on py3.15t; stdlib asyncio green on both).
