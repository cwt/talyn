# BUG-302 — Dead store in `accept_callback`

- **Status**: 🟢 Fixed (2026-08-23)
- **Severity**: 🟢 Low — Dead code
- **Files**:
  - `src/transports/streamserver/main.zig:226` (`_ = utils.get_data_ptr(Loop, @as(*Loop.Python.LoopObject, @ptrCast(loop)));`)
- **Lessons**: [Defensive Programming §Lesson 98](../lessons/10-defensive-programming-and-code-quality.md)
- **Description**: The computed pointer is discarded on the same line — a leftover from debugging. It executes on every accepted connection and confuses readers about whether loop validation is intended.
- **Trigger**: Every successful accept.
- **Consequences**: Pointless work in the accept hot path; misleading code.
- **Fix (Proposed)**: Delete the statement (or restore the intended validation it once performed).
