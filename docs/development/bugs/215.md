# BUG-215 — Context Argument Dropped in Runner.run

- **Status**: ✅ Fixed
- **Severity**: 🟢 Low — Python Asyncio API Inconsistency
- **Files**: `talyn/runner.py:29-32`
- **Lessons**: [Python C-API §Lesson 3](../lessons/003-python-c-api-best-practices.md)
- **Description**: In `talyn/runner.py`, `Runner.run(self, coro, *, context=None)` accepts a `context` parameter (matching the standard library `asyncio.Runner.run` API). However, its implementation uses `self._loop.run_until_complete(asyncio.ensure_future(coro, loop=self._loop))` which does not accept or pass the `context` parameter to the task creation.
- **Trigger**: Calling `runner.run(coro, context=custom_context)`.
- **Consequences**: Custom contextvars context is silently dropped and ignored.
- **Fix**: Use `self._loop.create_task(coro, context=context)` instead of `asyncio.ensure_future`.
